# Nipto brand assets

The official Nipto logo supplied by the founder is the source of truth for the launcher icon and splash artwork.

Required files:
- `nipto_logo.png`: original full logo, retained without cropping.
- `nipto_launcher.png`: square icon artwork derived from the app mark only.
- `nipto_launcher_foreground.png`: transparent foreground layer for Android adaptive launcher icons.

Brand palette:
- Deep navy: `#101C50`
- Cyan: `#08C9F4`
- Blue: `#0876F8`
- Violet: `#5528E8`
- Magenta: `#E516B8`
- Pink accent: `#FF4D9B`

Do not substitute a text glyph or a generic chat icon for the founder's official image in a release build. The current sign-in vector mark is an interim rendering.
